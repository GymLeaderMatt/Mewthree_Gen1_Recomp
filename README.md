# What it is:
- Adds the fusion of Mewtwo and Mew to the game.
- I take two stats from each, average the remainder.
- Stats: HP: 100, ATK: 105, DEF: 100, SPC: 154, SPD: 130

# Other stuff:
- I use Mewtwo's learnset with Transform over Disable for flavor.
- The growth rate is Medium Slow.
- The sprite is a fusion of Mewtwo's Red sprite and Mew's Yellow sprite.
- Dex number is 153 (in case it conflicts with other mods that add Pokemon).
